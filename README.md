# dwl-rc - [dwl](https://codeberg.org/dwl/dwl) fork with my custom patches

Thank you to all DWL contributors

### **dwl branch 0.7 and releases based upon 0.7 build against [wlroots] 0.18**

### dwl-rc has the following dependencies:
- libinput
- wayland
- wlroots (compiled with the libinput backend)
- xkbcommon
- wayland-protocols (compile-time only)
- pkg-config (compile-time only)
- fcft
- pixman
